# Codex project instructions

- Build a network-backed USB mass-storage appliance.
- The complete virtual disk remains on the SMB server.
- Do not replace the design with a complete local mirror.
- The USB device must be read-only.
- Published server images must be immutable.
- Never download or commit copyrighted game content.
- Use synthetic fixtures and user-supplied legal private test data only.
- Never record a test as passed unless it was actually executed.
- Preserve progress in BUILD_STATUS.json, WORKLOG.md, and RELEASE_GATES.md.
- Do not expose credentials in logs, command arguments, URLs, or reports.
- Treat Raspberry Pi 4 and Pi 5 as the main production targets.
- Treat Raspberry Pi Zero W as experimental until physical tests pass.
